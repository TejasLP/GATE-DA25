\item 
Which of the following statements is/are correct?
\hfill (DA~2025)
\begin{enumerate}
	\item $\mathbb{R}^n$ has a unique set of orthonormal basis vectors
	\item $\mathbb{R}^n$ does not have a unique set of orthonormal basis vectors
	\item Linearly independent vectors in $\mathbb{R}^n$ are orthonormal
	\item Orthonormal vectors in $\mathbb{R}^n$ are linearly independent
\end{enumerate}

\solution
From \eqref{eq:DA2025-orthonormal}, $\vec{u}_i^\top \vec{u}_j = \delta_{ij}$ guarantees that orthonormal sets are unconditionally linearly independent. Furthermore, orthonormal bases in $\mathbb{R}^n$ are non-unique.

To illustrate these properties with examples:
\begin{itemize}
	\item Non-uniqueness of Orthonormal Bases in $\mathbb{R}^n$:
	Consider $\mathbb{R}^2$. The standard canonical orthonormal basis is:
	\begin{align}
		\mathbf{B}_1 = \cbrak{\vec{e}_1 = \myvec{1 \\ 0}, \, \vec{e}_2 = \myvec{0 \\ 1}}
	\end{align}
	If we apply a spatial rotation by an angle $\theta = \frac{\pi}{4}$ ($45^\circ$), we obtain a completely different valid orthonormal basis:
	\begin{align}
		\mathbf{B}_2 = \cbrak{\vec{u}_1 = \myvec{\frac{1}{\sqrt{2}} \\ \frac{1}{\sqrt{2}}}, \, \vec{u}_2 = \myvec{-\frac{1}{\sqrt{2}} \\ \frac{1}{\sqrt{2}}}}
	\end{align}
	Since $\vec{u}_1^\top \vec{u}_2 = 0$ and $\norm{\vec{u}_1} = \norm{\vec{u}_2} = 1$, $\mathbf{B}_2$ satisfies all orthonormal basis requirements. This proves that $\mathbb{R}^n$ does not have a unique set of orthonormal basis vectors.
	
	\item Linearly Independent Vectors Need Not Be Orthogonal/Orthonormal:
	Consider two vectors in $\mathbb{R}^2$:
	\begin{align}
		\vec{v}_1 = \myvec{1 \\ 0}, \quad \vec{v}_2 = \myvec{1 \\ 1}
	\end{align}
	These vectors are linearly independent because neither is a scalar multiple of the other. However, they are not orthogonal (and thus not orthonormal) since their inner product is non-zero:
	\begin{align}
		\vec{v}_1^\top \vec{v}_2 = (1)(1) + (0)(1) = 1 \neq 0
	\end{align}
	This demonstrates that linear independence does not imply orthogonality or orthonormality.
\end{itemize}

	\item 0 is a singular value of $\vec{A}$
	\item Determinant of $\vec{A}$ is 0
	\item $\vec{z}^{\top}\vec{A}\vec{z} = 0$ for some non-zero $\vec{z} \in \mathbb{R}^n$
\end{enumerate}

From \eqref{eq:DA2025-quadratic-norm}, the following properties hold:
\begin{itemize}
	\item Positive Definiteness: For every $\vec{z} \neq \vec{0}$, $\vec{X}\vec{z} \neq \vec{0}$, which ensures $\norm{\vec{X}\vec{z}}^2 > 0$. Consequently:
	\begin{align}
		\vec{z}^{\top}\vec{A}\vec{z} > 0, \quad \forall \vec{z} \neq \vec{0}
	\end{align}
	which implies $\vec{z}^{\top}\vec{A}\vec{z} \neq 0$ for any non-zero $\vec{z}$.
	
	\item Eigenvalues and Invertibility: Let $\lambda$ be an eigenvalue of $\vec{A}$ with corresponding eigenvector $\vec{v} \neq \vec{0}$:
	\begin{align}
		\vec{A}\vec{v} = \lambda \vec{v} \implies \vec{v}^{\top}\vec{A}\vec{v} = \lambda \norm{\vec{v}}^2
	\end{align}

	\begin{align}
		\lambda = \frac{\vec{v}^{\top}\vec{A}\vec{v}}{\norm{\vec{v}}^2} > 0

	\begin{align}
