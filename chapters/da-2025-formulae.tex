\item Eigenvalues of Constant Row-Sum Matrices and System Solvability
\begin{align}
	\vec{A}\vec{1} = 1 \cdot \vec{1}, \quad \brak{\vec{A} - \vec{I}}\vec{1} = 0 \cdot \vec{1} \label{eq:DA2025-row_sum_eig}
\end{align}
\solution
Let $\vec{a}_i^\top$ denote the $i$-th row of $\vec{A} \in \mathbb{R}^{n \times n}$. Because the sum of the elements in each row is $1$, multiplying the row by the all-ones column vector $\vec{1} = \myvec{1 & 1 & \dots & 1}^\top$ yields:
\begin{align}
	\vec{a}_i^\top \vec{1} = 1, \quad \forall i \in \{1, 2, \dots, n\}
\end{align}
Grouping these row equations together to reconstruct the full matrix $\vec{A}$ gives:
\begin{align}
	\vec{A}\vec{1} &= \myvec{\vec{a}_1^\top \\ \vec{a}_2^\top \\ \vdots \\ \vec{a}_n^\top} \vec{1} 
	= \myvec{\vec{a}_1^\top \vec{1} \\ \vec{a}_2^\top \vec{1} \\ \vdots \\ \vec{a}_n^\top \vec{1}} 
	= \myvec{1 \\ 1 \\ \vdots \\ 1} = \vec{1} = 1 \cdot \vec{1}
\end{align}
This demonstrates that the vector $\vec{1}$ is an eigenvector of $\vec{A}$ associated with the eigenvalue $\lambda = 1$. 

To find the eigenvalue of $\vec{A} - \vec{I}$ corresponding to the same eigenvector $\vec{1}$:
\begin{align}
	\brak{\vec{A} - \vec{I}}\vec{1} = \vec{A}\vec{1} - \vec{I}\vec{1} = \vec{1} - \vec{1} = \vec{0} = 0 \cdot \vec{1}
\end{align}
Thus, $\vec{A} - \vec{I}$ possesses an eigenvalue of $0$, meaning it is a singular matrix ($\mydet{\vec{A} - \vec{I}} = 0$).

Number of Solutions for Linear Systems:

\begin{enumerate}
	\item For the system $\brak{\vec{A} - \vec{I}}\vec{x} = \vec{b}$:
	Because $\vec{A} - \vec{I}$ is singular ($\text{rank} < n$), the system will have infinitely many solutions if $\vec{b}$ is in the column space of $\vec{A} - \vec{I}$ (i.e., $\text{rank}\brak{\vec{A} - \vec{I}} = \text{rank}\brak{\sbrak{\vec{A} - \vec{I} \mid \vec{b}}}$), or no solution if it is not.
	
	\item For the system $\vec{A}\vec{x} = \vec{b}$:
	The number of solutions depends entirely on the remaining unknown eigenvalues of $\vec{A}$. If all other eigenvalues are non-zero ($\mydet{\vec{A}} \neq 0$), the system has a unique solution. If $0$ happens to also be an eigenvalue of $\vec{A}$, the matrix is singular, resulting in either no solution or infinitely many solutions
\end{enumerate}

\item Relational Algebra Natural Join
\input{figs/natural_join.tex}
\begin{align}
	R \bowtie S = \pi_{R \cup S}\brak{\sigma_{R.A = S.A}\brak{R \times S}} \label{eq:DA2025-join}
\end{align}
\solution
The equation describes the mechanical steps of combining two database tables using relational algebra operators:
\begin{itemize}
	\item $R$ and $S$: The two input relations (data tables) being operated on.
	\item $\bowtie$ (Natural Join): The overarching operator that merges $R$ and $S$ by matching rows with identical values in their common columns, outputting a single combined table with no duplicate columns.
	\item $R \times S$ (Cartesian Product): The foundational operation that pairs every single row in table $R$ with every single row in table $S$, generating all possible combinations.
	\item $\sigma_{R.A = S.A}$ (Selection): The row-filtering step. The $\sigma$ operator evaluates the Cartesian product and retains only the rows where the value in the shared attribute $A$ matches between both tables.
	\item $\pi_{R \cup S}$ (Projection): The column-filtering step. The $\pi$ operator dictates which columns appear in the final result. The subscript $R \cup S$ ensures that all unique columns from both tables are kept, effectively stripping out the redundant duplicate common column ($S.A$) generated by the Cartesian product.
\end{itemize}

\item General Moments of the Standard Normal Distribution

The expected value $E\sbrak{Z^n}$ for a standard normal variable $Z \sim \mathcal{N}\brak{0, 1}$ is defined by the integral:
\begin{align}
	E\sbrak{Z^n} &= \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{\infty} z^n e^{-z^2/2} \,dz \label{eq:DA2025-normal_moment_integral}
\end{align}

For odd powers ($n = 2k + 1$), the integrand is an odd function symmetric about the origin:
\begin{align}
	E\sbrak{Z^{2k+1}} &= 0 \label{eq:DA2025-normal_moment_odd}
\end{align}

For even powers ($n = 2k$), integrating by parts ($u = z^{n-1}$, $dv = z e^{-z^2/2} dz$) yields:
\begin{align}
	\int_{-\infty}^{\infty} z^n e^{-z^2/2} \,dz &= \sbrak{-z^{n-1} e^{-z^2/2}}_{-\infty}^{\infty} + \int_{-\infty}^{\infty} \brak{n-1} z^{n-2} e^{-z^2/2} \,dz
	\intertext{The boundary term decays to zero. Multiplying by the normalization constant establishes the recurrence relation:}
	E\sbrak{Z^n} &= \brak{n-1} E\sbrak{Z^{n-2}}
	\intertext{Expanding recursively to the base case $E\sbrak{Z^0} = 1$ gives the expanded product:}
	E\sbrak{Z^n} &= \brak{n - 1} \cdot \brak{n - 3} \cdots 3 \cdot 1 \label{eq:DA2025-normal_moment_even}
\end{align}

	\item Binary Search Complexity
	\begin{align}
		T\brak{n} &= T\brak{n/2} + O\brak{1} \label{eq:DA2025-binary_recurrence}
		\\
		T\brak{n} &= O\brak{\log n} \label{eq:DA2025-binary_search}
	\end{align}
	\solution
	Binary search operates by halving the search space at each step. Let $c$ represent the constant $O\brak{1}$ time required to access the middle element. Expanding the recurrence relation iteratively yields:
	\begin{align}
		T\brak{n} &= T\brak{\frac{n}{2}} + c
		\\
		&= \brak{T\brak{\frac{n}{4}} + c} + c
		\\
		&= T\brak{\frac{n}{2^2}} + 2c
		\\
		&= T\brak{\frac{n}{2^k}} + kc
	\end{align}
	The recursion strictly terminates when the array size reduces to $1$. 
	\begin{align}
		\frac{n}{2^k} &= 1
		\\
		n &= 2^k
		\\
		k &= \log_2 n
	\end{align}
	Substituting $k$ back into the expanded equation:
	\begin{align}
		T\brak{n} &= T\brak{1} + c \log_2 n
		\\
		&= O\brak{\log n}
	\end{align}
	This logarithmic performance bound relies entirely on executing the $O\brak{1}$ constant-time midpoint calculation, restricting its use strictly to contiguous memory structures like arrays, rendering it incompatible with linked lists.

Given the condition $x^\top x = a$, we can determine the eigenvalues by evaluating the standard eigenvalue equation $A v = \lambda v$ across the two geometric subspaces defined by $x$.

\begin{align}
	A x &= \brak{I_n + x x^\top}x
	\\

	\\
	&= x + x\brak{a}
	\\
	&= \brak{1 + a}x
\end{align}
yielding a single eigenvalue of $\lambda_1 = 1 + a$.

For any eigenvector $v$ orthogonal to $x$ (meaning $x^\top v = 0$):
\begin{align}
	A v &= \brak{I_n + x x^\top}v
	\\
	&= v + x\brak{x^\top v}
	\\
	&= v + x\brak{0}
	\\
	&= 1v
\end{align}
yielding an eigenvalue of $\lambda_2 = 1$ with multiplicity $n-1$.

To derive the corresponding eigenvalues for the inverse matrix $A^{-1}$, we use the defining property of eigenvalues $A v = \lambda v$ and left-multiply both sides by $A^{-1}$:
\begin{align}
	A^{-1} \brak{A v} &= A^{-1} \brak{\lambda v}
	\\
	\brak{A^{-1} A} v &= \lambda \brak{A^{-1} v}
	\\
	I_n v &= \lambda A^{-1} v
	\\
	v &= \lambda A^{-1} v
	\\
	A^{-1} v &= \frac{1}{\lambda} v
\end{align}
This proves that any eigenvector $v$ of $A$ is also an eigenvector of $A^{-1}$, and its corresponding eigenvalue is exactly the reciprocal $\frac{1}{\lambda}$. Substituting our previously derived values, the eigenvalues of $A^{-1}$ are $\frac{1}{1+a}$ and $1$.

\item Least Squares Regression Through Origin
\begin{align}
	w^* &= \frac{\sum x_i y_i}{\sum x_i^2}
\end{align}
\solution

The objective function $S\brak{w}$ represents the Sum of Squared Residuals (SSR), which measures the total squared penalty between the actual observed values $y_i$ and the model's predictions $\hat{y}_i$:
\begin{align}
	S\brak{w} &= \sum \brak{y_i - \hat{y}_i}^2
	\\
	&= \sum \brak{y_i - w x_i}^2
\end{align}
To determine the optimal parameter $w^*$ that minimizes this cumulative error, evaluate the derivative of $S\brak{w}$ with respect to $w$ and equate it to zero to solve for the global minimum symbolically:
\begin{align}
	\frac{dS}{dw} &= -2 \sum x_i \brak{y_i - w x_i} = 0
	\\
	\sum x_i y_i - w \sum x_i^2 &= 0
	\\
	w^* &= \frac{\sum x_i y_i}{\sum x_i^2}
\end{align}

\item Isometric Norm Preservation
\begin{align}
	\|\mathbf{Ax}\|^2 &= \|\mathbf{x}\|^2 \iff \mathbf{A}^\top\mathbf{A} = \mathbf{I}
\end{align}
\solution
By the definition of the Euclidean norm in terms of the standard inner product, evaluate both sides for an arbitrary vector $\mathbf{x} \in \mathbb{R}^n$:
\begin{align}
	\|\mathbf{Ax}\|^2 &= \brak{\mathbf{Ax}}^\top \brak{\mathbf{Ax}} = \mathbf{x}^\top \mathbf{A}^\top \mathbf{A} \mathbf{x}
	\\
	\|\mathbf{x}\|^2 &= \mathbf{x}^\top \mathbf{x} = \mathbf{x}^\top \mathbf{I} \mathbf{x}
\end{align}
Equating the two expanded forms for all $\mathbf{x}$:
\begin{align}
	\mathbf{x}^\top \mathbf{A}^\top \mathbf{A} \mathbf{x} &= \mathbf{x}^\top \mathbf{I} \mathbf{x}
	\\
	\mathbf{x}^\top \brak{\mathbf{A}^\top \mathbf{A} - \mathbf{I}} \mathbf{x} &= 0
\end{align}
The matrix $\brak{\mathbf{A}^\top \mathbf{A} - \mathbf{I}}$ is inherently symmetric. If a quadratic form of a symmetric matrix evaluates to zero for all possible vectors $\mathbf{x}$, the matrix must be the zero matrix. Therefore:
\begin{align}
	\mathbf{A}^\top \mathbf{A} - \mathbf{I} &= \mathbf{0} \implies \mathbf{A}^\top \mathbf{A} = \mathbf{I}
\end{align}

\item Properties of Sample Proportion
\begin{align}
	E\sbrak{\hat{p}} &= p 
	\\
	var\brak{\hat{p}} &= \frac{p\brak{1-p}}{n}
\end{align}

From the defined moments of a Binomial distribution:
\begin{align}
	E\brak{X} &= np 
	\\
	var\brak{X} &= npq = np\brak{1-p} 
\end{align}

The sample proportion is given as $\hat{p} = \frac{X}{n}$. Evaluating the expectation yields:
\begin{align}
	E\sbrak{\hat{p}} &= E\sbrak{\frac{X}{n}}
	\\
	&= \frac{1}{n} E\brak{X}
	\\
	&= \frac{1}{n} \brak{np} = p
\end{align}

To evaluate the variance, apply the fundamental variance scaling property $var\brak{aX} = a^2 var\brak{X}$ established in the text:
\begin{align}

	\\
	&= \frac{1}{n^2} var\brak{X}
	\\
	&= \frac{1}{n^2} \sbrak{np\brak{1-p}}
	\\
	&= \frac{p\brak{1-p}}{n}
\end{align}

Because $n$ is in the denominator of the resulting expression, the variance of $\hat{p}$ strictly decreases as the total number of independent coin tosses $n$ increases. Therefore, statements (A) and (C) are correct.
